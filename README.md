# 图提取 ImageGrab

在淘宝、京东、拼多多商家版的商品详情页，一键提取页面里的全部图片，集中预览、自由勾选，批量下载为 PNG。

- 扩展版本：1.0.0（Manifest V3）
- 支持浏览器：Chrome、Edge（Chromium 内核，版本 102+）
- 官网（纯静态）：`docs/index.html`

---

## 一、安装（加载到浏览器）

1. **下载并解压**
   把 `ImageGrab-extension-v1.0.0.zip` 解压到本地任意文件夹。解压后的文件夹里应当能直接看到 `manifest.json`（不要多套一层目录）。

2. **打开扩展管理页**
   打开 Chrome，地址栏输入 `chrome://extensions` 回车。

3. **开启开发者模式**
   打开页面右上角的「开发者模式」开关。

4. **加载扩展**
   点击「加载已解压的扩展程序」，选中第 1 步解压出来的文件夹。
   加载成功后，工具栏会出现「图提取」的图标，扩展卡片上会显示版本 1.0.0。

> 更新版本时：回到 `chrome://extensions`，点击插件卡片上的刷新图标即可重新加载；改完源码后建议再刷新一次。

---

## 二、使用

1. 打开任意一个**商品详情页**（淘宝 / 天猫 / 京东 / 拼多多商家版）。
2. 页面**右下角**会出现「获取图片」按钮，点击它。
3. 稍等片刻，浏览器会打开一个新标签页「图片画廊」，以网格展示扫描到的所有图片，并显示每张图的真实尺寸。
4. 在画廊里勾选需要的图片（支持**全选 / 反选 / 逐张点击**；默认已全选）。
   - 勾选「忽略小于 100×100」时，加载后被发现是小图的会自动取消勾选并标记「过小」。
5. 点击右上角「**下载选中为 PNG**」。
6. 图片会保存到浏览器**下载目录下的 `图提取` 文件夹**，文件名按序号编号：`商品图_001.png`、`商品图_002.png`……

工具栏上的扩展图标也可直接点开画廊，查看上一次的提取结果。

## 三、关于跨域（PNG 转换失败时）

图片统一转成 PNG 需要先把原图读进内存再重绘，这一步受浏览器同源策略限制。扩展在 `manifest.json` 里已声明了三个平台域名及其常用图片 CDN：

```
*.taobao.com  *.tmall.com  *.jd.com  *.pinduoduo.com  *.yangkeduo.com
*.alicdn.com  *.taobaocdn.com  *.tbcdn.cn  *.360buyimg.com  *.3.cn  *.pddpic.com
```

多数商品图都在上述域名内，可直接转换成功。

如果遇到**少数图片转换失败**（画廊里会标记「PNG 失败」），有两种处理方式：

- 点击画廊空状态或失败提示里的「**授予全部站点访问权限（跨域兜底）**」，授权后再重新提取下载；
- 或者接受失败，改用「下载原图」按原始格式（jpg / webp）保存。

> 说明：扩展本身不上传任何数据，所有图片解析、格式转换都在本机浏览器内完成，不会发送到任何服务器。

## 四、目录结构

```
ImageGrab/
├─ manifest.json        # 扩展清单（Manifest V3）：权限、域名、入口
├─ content.js           # 注入右下角按钮 + 扫描页面图片（含懒加载与背景图）
├─ content.css          # 悬浮按钮与页面内提示的样式
├─ background.js        # Service Worker：消息转发、结果暂存、抓图转 PNG 并下载
├─ gallery.html         # 图片画廊页
├─ gallery.js           # 画廊逻辑：渲染、勾选、批量下载与进度
├─ gallery.css          # 画廊样式（响应式网格）
├─ icons/               # 扩展图标 16 / 32 / 48 / 128
├─ README.md            # 本文件
└─ docs/                # 官方宣传网站（纯静态，双击 index.html 即可打开）
   ├─ index.html
   ├─ css/style.css
   ├─ js/main.js
   └─ assets/
```

## 五、查看官网

直接用浏览器打开 `docs/index.html` 即可，无需任何构建工具或后端。
官网首屏有一个**可交互的插件演示**：点击演示窗口右下角的「获取图片」，可以看到画廊滑入、勾选图片、模拟下载的完整流程。

修改主色调只需改 `docs/css/style.css` 中 `:root` 的 `--grad`（渐变）与 `--indigo` 等变量。

## 六、常见问题

**Q：点了「获取图片」提示「未找到图片」？**
A：说明当前页面上符合条件（尺寸 ≥ 100×100、非图标/占位图）的图片为空。先滚动页面让图片加载出来，再点一次；长图列表页请滚动到底部后再提取。

**Q：按钮没有出现？**
A：确认当前页面属于支持平台，且在 `chrome://extensions` 里已启用本扩展。若某平台改版导致识别失效，可把 `content.js` 顶部的 `DETAIL_ONLY` 保持为 `false`（默认即全站显示）。

**Q：下载的图片尺寸偏小？**
A：部分平台会给同一张图提供多个尺寸版本（如 `xxx_50x50.jpg`、`xxx_430x430.jpg`）。扩展会过滤掉过小的版本，并尽量保留较大的那张。

## 七、开发提示

- 三个平台的懒加载属性各不相同，已在 `content.js` 的 `LAZY_ATTRS` 中统一兼容（`data-src`、`data-original`、`data-lazy-img`、`data-ks-lazyload` 等）。
- 最小尺寸阈值 `MIN_SIZE`、并发下载数 `CONCURRENCY` 等常量都集中在各文件顶部，便于按需调整。
- 下载文件名规则在 `background.js` 的 `normalizeFilename()` 中，默认输出到 `图提取/` 子目录。
